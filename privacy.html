Myplan 개인정보처리방침

시행일: 2026년 11월 19일

1. 어떤 정보를 쓰나요

사용자가 Google 계정으로 로그인하면 Myplan은 Google API로 다음 정보에 접근합니다.

  • Google 캘린더: 캘린더 목록과 일정 (보기, 만들기, 고치기, 지우기)
  • Gmail: 메일 목록, 본문, 첨부, 라벨 (읽기, 보내기, 정리)
  • 기본 프로필: 이메일 주소 (계정 구분용)

2. 어디에 저장하나요

가져온 정보와 로그인 토큰은 사용자 PC 안(%APPDATA%\Myplan)에만 저장됩니다. 토큰은 Windows 데이터 보호(DPAPI)로 암호화합니다. Myplan에는 개발자가 운영하는 서버가 없으며, 정보는 사용자 PC와 Google 사이에서만 오갑니다.

3. 누구와 공유하나요

누구와도 공유하거나 판매하지 않습니다. 광고, 분석, 제3자 서비스에 보내지 않습니다. 인공지능 모델 학습에 쓰지 않습니다.

4. Google API 사용자 데이터 정책

Myplan이 Google API에서 받은 정보를 쓰고 다른 앱으로 넘기는 방식은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 지우는 방법

앱에서 계정 연결을 끊거나 앱을 제거하면 PC에 저장된 정보가 지워집니다. Google 계정의 타사 앱 액세스에서 언제든 권한을 취소할 수 있습니다.
