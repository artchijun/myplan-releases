# Myplan

캘린더 · 메일 · 메모 · 클립보드를 한 창에서 다루는 Windows 앱입니다.

## 설치

[최신 릴리스](https://github.com/artchijun/myplan-releases/releases/latest)에서 `Myplan-setup.exe`를 받아 실행하세요.
관리자 권한 없이 설치되고, 새 버전이 나오면 앱이 알려 줍니다(설정 → 정보에서도 확인·설치).

제거: Windows 설정 → 앱 → 설치된 앱 → Myplan

이 저장소에는 설치 파일과 홈페이지(index.html, privacy.html)만 있습니다. 소스는 비공개 저장소에 있습니다.
